# 모델 ② 눈부심 정도 분류 — 시범 검증 (2026-10-30)

전방 화면 한 장을 **정상 / 눈부심 / 심한 눈부심** 3단계로 나눌 수 있는지, 딥러닝 없이 화면에서 뽑은 숫자 + 트리 모델로 시험했다.

## 결론

| 방법 | 정확도 | macro F1 | 심한 눈부심 재현율 |
|---|---|---|---|
| 규칙: 화면 전체 밝기 | 0.38 | 0.33 | 0.07 |
| 규칙: 하얀 픽셀 비율 | 0.35 | 0.32 | 0.19 |
| **LightGBM (화면 숫자 12개)** | **0.58** | **0.57** | **0.52** |

- 단순 밝기 규칙은 3단계 무작위(0.33)와 비슷하다. 화면 숫자를 조합한 모델이 확실히 낫다.
- 중요 변수(gain): 밝은 덩어리 크기 20% · 가장 밝은 점 가로 위치 18% · 도로 선명도 12% · 희뿌연 정도 10% · 전체 밝기 8%
- 가장 많이 틀린 곳은 정상 ↔ 눈부심 경계 (사람도 애매한 구간)

```
혼동행렬 (행 = 정답, 열 = 예측: 정상 / 눈부심 / 심한)
정상     29  15   3
눈부심   16  32   8
심한      4   9  14
```

## 데이터

- [GLARE](https://github.com/NicholasCG/GLARE_Dataset) (Gray et al., 2023, IEEE T-ITS, CC BY 4.0): 미국 플로리다 블랙박스 영상 33개에서 뽑은 눈부심 장면 2,157장
- 영상마다 화면 숫자 기준 약함 → 강함 4장씩 골라 **130장**에 시범 라벨 (정상 47 · 눈부심 56 · 심한 27)
- 원본 이미지와 라벨 CSV는 저장소에 올리지 않는다 (`.gitignore`). 노션 「실험 기록」에 위치를 적어 둔다

## 라벨 기준 (시범)

| 라벨 | 기준 |
|---|---|
| 0 정상 | 해가 화면에 없고, 도로 · 차선 · 신호가 다 보인다 |
| 1 눈부심 | 해나 강한 역광이 보이지만, 도로 · 차선 · 신호는 읽힌다 |
| 2 심한 눈부심 | 해가 신호 · 표지판 · 도로 바로 위에 있거나, 하얗게 번져서 일부가 안 보인다 |

## 검증 방법

위 표는 기존 시범 라벨 기준입니다. **팀원 2인 독립 검수는 태양의 존재보다 화면 시인성을 기준**으로 합니다. 태양이 보여도 도로·차선·표지·신호가 명확하면 정상, 번짐·대비 저하가 있으나 필요한 정보가 읽히면 눈부심, 필요한 정보 일부가 가려져 판독이 어려우면 심한 눈부심으로 검토합니다. 밤·측면·높은 태양도 판정 대상이며 눈부심 이외의 어둠·흔들림·가림은 따로 표시해 혼동하지 않습니다. 새 기준으로 검수한 결과는 새 라벨 버전으로 저장하고 기존 0.57과 동일 데이터 정답인 것처럼 비교하지 않습니다.

- 같은 영상의 프레임은 거의 같은 사진이다 (심한 점수 분산의 84%가 영상 사이 차이). 그래서 **영상(vid) 단위 GroupKFold 5겹**으로 나눴다
- 규칙 기준선의 임계값은 학습 폴드에서만 정했다
