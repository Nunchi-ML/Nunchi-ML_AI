## 3. 코드 개선 사항 (코드 리뷰 반영)

1. **`bearing.py`**:
   - 노선 양 끝점과의 거리 계산을 단순 위경도 제곱차에서 **하버사인 구면 대원 거리(Haversine Distance)**로 전면 교체.
   - 방향 매핑 실패 시 임의로 `True`로 처리하던 기본값을 제거하고 `np.nan` 및 예외 로깅 추가 (검증 결과 4,458건 전체에 대해 100.0% 매핑 성공 확인).
2. **`build_segments.py`**:
   - `segment_length_km`을 `len(grp) * 0.1` 추정 대신 `max(이정) - min(이정)` 실제 이정 스팬으로 산출하고, 0.8 km 미만 구간 52개를 `is_partial_segment`로 플래그화.
   - 출퇴근 시간대를 기존 3시간(7~9시, 17~19시)에서 **엄밀한 2시간 구간(07:00~08:59, 17:00~18:59)**으로 정밀 보정.
   - 터널 데이터 부재 시의 인덱싱 오류 예외 처리 및 터널 입출구 개수 정의 명확화.
3. **`train_poisson.py`**:
   - 폴드별 성능 편차(mean ± std), 사고 발생 구간($y>0$) MAE, 상위 10% 위험 구간 사고 포착률(Capture Rate) 산출 기능 추가.
