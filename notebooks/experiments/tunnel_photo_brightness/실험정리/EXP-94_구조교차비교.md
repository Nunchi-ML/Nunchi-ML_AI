# [모델 ③] EXP-94(가번호) 구조 교차 비교: ML 구조 ↔ 규칙 구조

작성: 2026-11-06. 코드: `sunsight_video/10_등급2단계_로지스틱.ipynb`의 6장. 결과 표 파일 3개는 이 폴더에 있다.
- `EXP-94_구조교차_결과표.csv`
- `EXP-94_구조교차_짝차이.csv`
- `EXP-94_구조교차_학습OOF짝차이.csv`

## 1. 배경

최재혁은 모델②와 같은 방식으로 ML의 당위성을 보이자고 지시했다.

- ML에서 잘 된 구조는 규칙에도 씌운다.
- 규칙에서 잘 된 구조는 ML에도 씌운다.
- 마지막으로 ML 최고 구조와 비교한다.

이렇게 하는 이유는 하나다. "ML이 이겼다"가 구조(틀) 덕분인지, 학습(가중치를 데이터로 정함) 덕분인지 가려야 하기 때문이다.

## 2. 데이터와 방법

| 항목 | 내용 |
|---|---|
| 학습 | AI허브 71786 3,624장, 2023년 8\~9월, 카메라 1기종. 터널 입구 1,927장 + 터널 없는 고속도로 1,697장. 출구 0장 |
| 시험 (주 판정) | Mapillary 터널 입구 66장, 51장면, 다른 카메라, 여러 달. 시험 정의 ②a (71786만으로 학습) |
| 정답 | 천리안 일사량 E(촬영 시각·위경도) → 바깥 밝기 L20 → 입구 휘도비 → 상/중/하 (10배·15배 경계) |
| 고르는 법 | 구조마다 규칙 쪽 후보와 ML 쪽 후보 가운데 학습 71786 장면 단위 5겹 OOF F1이 1등인 것만 시험에 냄. 시험 점수를 보고 고르지 않음 |
| 채점 | 입구 66장 3등급 Macro F1. 장면 단위 bootstrap 1,000번. 짝지은 차이의 95% 하한이 0보다 크면 우위 (모델②와 같은 기준) |
| 보조 채점 | 학습 쪽 OOF(입구 1,927장, 736장면)에서도 같은 짝지은 차이를 계산. 같은 카메라라 새 카메라 일반화의 근거는 아님 |
| 뺀 것 | 규칙5(11/6 결정), 출구(11/5 결정) |

## 3. 구조 4가지

| 구조 | 규칙 쪽 | ML 쪽 |
|---|---|---|
| ① 밝기 추정 → 공식 등급 | 규칙1\~4의 밝기 → 공식 | 직선 회귀(Ridge) 밝기 → 공식 |
| ② 2단계 직접 분류 (사진+해높이+구름) | 단계마다 숫자 하나에 경계 하나 (if 한 줄) | 단계마다 로지스틱 회귀 |
| ③ 추정 밝기 + 2단계 (ML 최고 구조를 규칙에) | 규칙1\~4 밝기를 13번째 변수로 넣고 2단계 if | 직선 회귀 밝기를 13번째 변수로 넣고 2단계 로지스틱 (= 주 모델) |
| ④ 해 높이 하나로 2단계 (규칙 최고 구조를 ML에) | 해 높이 경계 2개 | 해 높이만으로 2단계 로지스틱 |

## 4. 결과 (시험: Mapillary 입구 66장, ②a)

| 구조 | 규칙 (고른 것) | 규칙 F1 | ML (고른 것) | ML F1 | ML − 규칙 (95% 범위) | 판정 |
|---|---|---|---|---|---|---|
| ① 밝기 → 공식 | 규칙4 물리 공식 | .427 | 직선 회귀 | .516 | +.085 (−.045\~.220) | 비슷 |
| ② 2단계 직접 | 2단계 if | .789 | 로지스틱 C=.01 | .824 | +.036 (−.084\~.151) | 비슷 |
| ③ 추정 밝기 + 2단계 | 물리 공식 밝기 + 2단계 if | .581 | 주 모델 C=.01 | **.844** | **+.266 (.072\~.424)** | **ML 이김** |
| ④ 해 높이 하나 | 해 높이 경계 2개 | .789 | 해 높이 로지스틱 C=1 | .759 | −.031 (−.078\~.000) | 비슷 (규칙이 약간 위) |

ML 최고(주 모델 .844)를 각 구조의 최고 규칙과 비교한 결과다.
- 대 물리 공식(.427): +.421 (.22\~.61), 이김
- 대 물리 밝기 + 2단계 if(.581): +.266, 이김
- 대 2단계 if(.789): +.057 (−.06\~.17), 비슷

## 6. 원인 분석 (비판적으로)

1. **"추정 밝기 + 2단계" 틀은 ML일 때만 힘을 낸다.** 같은 틀에 규칙 밝기(물리 공식)를 넣으면 .581로 떨어진다. ML 밝기는 R² .77, 물리 공식은 .39다. 밝기를 데이터로 배운 것이 핵심이고, 이것이 ML 당위성의 가장 강한 근거다.
2. **가장 좋은 규칙은 "해 높이 경계 2개"다(.789).** 사진+해높이+구름 12개를 줘도 규칙은 결국 해 높이만 골랐다. 그래서 ②와 ④의 규칙 점수가 같다. 이 규칙을 ML로 바꿔도(.759) 나아지지 않는다. 숫자 하나만 쓰면 ML의 장점이 없다.
3. **새 카메라 66장에서는 주 모델이 최고 규칙을 확정적으로 이기지 못한다(+.057, 하한 −.06).** 시험이 51장면뿐이라 범위가 넓다. 12월 22장이 전부 하, 5월 28장이 전부 상이라 해 높이만으로 대부분 맞힌다는 점도 영향을 준다.
4. **학습 쪽 OOF(736장면)에서는 주 모델이 해 높이 규칙을 이긴다(+.055, 하한 .025).** 다만 같은 카메라이고 8\~9월뿐이다. 그리고 C를 이 OOF로 골랐다. 후보는 3개뿐이라 부풀림은 작지만 없지는 않다.

## 7. 결론과 발표 문장

- 같은 틀(추정 밝기 + 2단계)에서는 ML이 규칙을 확실히 이긴다(+.266, 하한 .072). 이 차이는 "학습한 밝기" 덕분이다.
- 가장 좋은 규칙(해 높이 경계)과 비교하면 이렇다. 같은 카메라에서는 ML이 이긴다(+.055, 하한 .025). 새 카메라에서는 좋아지는 경향(+.057)만 있고 확정은 아니다.
- 한계 한 줄: 새 카메라 시험 사진이 66장(51장면)이고 계절로 갈려서, 해 높이 규칙과의 차이를 확정하기에는 부족하다.
- 개선안: 11월\~4월(해가 낮은 계절)의 Mapillary 입구 사진을 더 모은다. 특히 "중" 등급이 섞이는 달을 모아 장면 수를 늘린다.
