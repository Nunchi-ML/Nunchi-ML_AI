# [모델 ③] EXP-55c 사진분류 반영: 입구·출구가 보이는 사진만

실행 2026-11-05 · 노트북 `07_밝기추정_규칙vsML.ipynb` · 공통 규칙 1판 · 담당 최재혁
상태: **결과 나옴, 사진이 적어 결론 보류** (EXP-55b의 후속)

---

## 1. 왜 했나

EXP-55b에서 GPS로만 고른 사진 중 터널 입구가 안 보이는 사진이 섞여 있었다.
사람이 사진을 직접 분류해 **입구나 출구가 실제로 보이는 사진만** 남기면 사진 숫자가 쓸모를 갖는지 확인했다.

## 2. 쓴 데이터

| 항목 | 내용 |
|---|---|
| 분류 | 최재혁이 Mapillary 96장을 **두 번** 분류 (`사진분류_도구.html`). 자기 일치율 **94%** |
| 남긴 사진 | 두 번 다 같은 답이 나온 사진 중, 입구·출구이면서 천리안 정답이 있는 사진 |
| 사진 수 | **46장 · 37장면** (입구 32 · 출구 14) |
| 정답 | 천리안 (입구 = 280 × 조광단계, 출구 = 45로 나눔) |
| 정답 등급 분포 | 상 28 · 중 4 · 하 14 |
| 나누는 법 | 장면 단위 5겹 × 10번 반복 |

## 3. 모델

EXP-55b와 같은 9개 (규칙 5 · ML 4).

## 5. 읽는 법

- 입구가 보이는 사진만 남기니 **사진 숫자가 의미를 갖기 시작했다.** 사진 규칙의 F1이 .2대 → .4\~.5대.
- 입구 32장만 보면 다섯 모델이 .61\~.67로 거의 같다. 사진 ML(.65)이 규칙5(.61)를 처음 앞섰다.
- 사진을 더해도(비교③) 여전히 나아지지 않는다.

## 6. 믿기 어려운 점

1. **46장 · 37장면뿐**이라 점수가 크게 흔들림
2. **"중"이 4장뿐**이라 한 장만 틀려도 F1이 크게 바뀜
3. **출구 사진은 ÷45라 거의 전부 "상"** → 출구가 섞이면 F1이 쉽게 오름
4. 아직 분류 안 된 사진 76장이 남음
