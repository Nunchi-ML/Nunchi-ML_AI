## 2. 사진에서 뽑은 숫자 10개 (사진 규칙과 ML이 공통으로 받음)

| 숫자 | 뜻 |
|---|---|
| sky_mean | 위 1/3(하늘) 평균 밝기 |
| blue_sky | 하늘 중 파란 하늘 비율 |
| white_ratio | 하얗게 날아간 칸 비율 |
| shadow_contrast | 아래 1/3(도로) 밝은 곳 − 어두운 곳 차이 = 그림자 진하기 |
| road_mean | 도로 평균 밝기 |
| sky_road_ratio | 하늘 ÷ 도로 밝기 |
| portal_ratio | 터널 구멍 주변 ÷ 구멍 밝기 (로그). Mapillary는 구멍 표시가 없어 가운데에서 가장 어두운 15%를 구멍으로 봄 |
| saturation | 색 진하기 |
| spread | 사진 전체 밝기 퍼짐 |
| mean_all | 사진 전체 평균 밝기 (카메라 자동 노출 영향 큼, 비교용) |

## 3. 각 모델이 받은 입력과 학습한 것

| 모델 | 구분 | 입력 | 학습하는 것 | 한 줄 설명 |
|---|---|---|---|---|
| 규칙1 손 규칙 | 규칙 · 사진 | 사진 숫자 6개 | **없음** | 파란 하늘 > 0.20이면 +2, 그림자 > 0.35 +1, 하늘 밝기 > 0.60 +1, 날아간 비율 > 0.01 +1, 색 > 0.20 +1, 퍼짐 < 0.5 −1 → 점수(−1~6)를 500~5,000 cd/m²로 바꿈. 데이터 보기 전에 고정 |
| 규칙2 경계값 학습 | 규칙 · 사진 | 사진 숫자 6개 | 경계값, 점수별 밝기 | 규칙1과 모양 같음. 경계를 학습 사진의 중간값으로, 점수→밝기를 학습 사진 평균으로 |
| 규칙3 숫자 하나 직선 | 규칙 · 사진 | 사진 숫자 1개 (10개 중 제일 잘 맞는 것) | 기울기 · 절편 | 숫자 하나로 직선 하나 |
| 규칙4 물리 공식 | 규칙 · **사진 안 씀** | 해 높이 + 구름 | **없음** | 맑은 하늘 일사(Haurwitz 1945) × 구름 감쇠(Kasten & Czeplak 1980) |
| 규칙5 계절·구름 표 | 규칙 · **사진 안 씀** | 달(계절) + 구름 | 칸별 평균 | 계절 4 × 구름 3칸(맑음 <3 · 보통 · 흐림 ≥8) 표 |
| 선형회귀 | ML · 사진 | 사진 숫자 10개 | 가중치 | 숫자마다 가중치 곱해 더함 (Ridge). 숫자끼리 조합은 못 봄 |
| LightGBM | ML · 사진 | 사진 숫자 10개 | 나무 구조 | 숫자 조합까지 봄 (나무 300개, 잎 7개) |
| LightGBM+ | ML · 사진+α | 사진 숫자 10개 + 해 높이 + 구름 | 나무 구조 | 사진 + 시각·날씨 정보 |

## 5. 결과 (10번 반복 평균)

| 모델 | 입력 | MAE(log) | 순위상관 | 위험도F1 |
|---|---|---|---|---|
| 규칙1 손 규칙 | 사진 | .420 | .17 | .21 |
| 규칙2 경계값 학습 | 사진 | .374 | .17 | .15 |
| 규칙3 숫자 하나 직선 | 사진 | .365 | .22 | .18 |
| 선형회귀 | 사진 | .262 | .53 | .36 |
| LightGBM | 사진 | .214 | .64 | .49 |
| 규칙4 물리 공식 | 해 높이 · 구름 | .105 | .91 | .68 |
| 규칙5 계절·구름 표 | 계절 · 구름 | .075 | .80 | .69 |
| LightGBM+ | 사진 + 해 높이 · 구름 | .077 | .89 | **.75** |

비교 기준선: 전부 "상"으로 찍기 = 위험도F1 약 .25

## 6. 읽는 법

- **사진만 쓰는 경우**: ML(LightGBM .49)이 사진 규칙(.15~.21)보다 확실히 나음. 사진 규칙 셋은 **찍기(.25)보다도 못함**
- **사진 안 쓰는 규칙이 사진 ML보다 나음**: 바깥 밝기는 대부분 "해가 얼마나 높나 + 구름"으로 정해지는데, 사진 한 장은 카메라 자동 노출 때문에 그 정보를 흐림
- **LightGBM+가 가장 좋음(.75)**: 사진이 해 높이 · 구름 위에 "그 자리 실제 하늘"을 조금 더해 줌. 다만 규칙5와 차이(.06)는 흔들림 안쪽일 수 있음
- 순위상관은 밝기 줄 세우기라 규칙4가 가장 높음(.91). 위험도F1이 그만큼 안 오르는 이유 = 톱니 모양 위험도 공식 (공통 규칙 5번)

## 7. 이 결과를 믿기 어려운 점

1. **정답과 입력이 같은 관측소**: 규칙5 · LightGBM+의 구름과 정답 일사량이 같은 ASOS 관측소에서 옴 → 사진 안 쓰는 쪽이 유리하게 나옴. 천리안 정답으로 바꾸면 줄어들 것
2. **105장 · 78장면**: 한 겹 시험에 16장면 정도라 점수가 크게 흔들림
3. **전부 입구 가정**: 출구 사진이 섞여 있으면 등급이 틀림 (출구는 ÷45라 대부분 상)
4. **사진 숫자의 터널 구멍이 추정**: Mapillary는 구멍 표시가 없음
