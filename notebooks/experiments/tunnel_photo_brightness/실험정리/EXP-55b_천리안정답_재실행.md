# [모델 ③] EXP-55b 천리안 정답으로 다시 돌리기

실행 2026-11-05 · 노트북 `07_밝기추정_규칙vsML.ipynb` · 공통 규칙 1판(`00_공통_정답과_채점.md`) · 담당 최재혁
상태: **결과 나옴** (EXP-55의 후속. 정답만 ASOS → 천리안으로 바꿈)

---

## 1. 왜 했나

EXP-55는 정답과 구름 입력이 **같은 ASOS 관측소**에서 와서, 사진을 안 쓰는 모델이 유리했을 수 있다.
그래서 정답을 사진 위치 바로 그 점의 **천리안 위성 일사량**으로 바꿔 같은 비교를 다시 했다.

## 2. 쓴 데이터

| 항목 | 내용 |
|---|---|
| 사진 | Mapillary 고속도로 터널 사진 **141장 = 104장면** (EXP-55의 105장보다 늘어남) |
| 뺀 사진 | 지하차도, 일사량 0.05 MJ/m² 이하(밤 · 해 질 녘) |
| 정답 | **천리안2A** 일사량 (촬영 시각 · 위경도, 다음 정시 1시간 값) → L20 → 휘도비 → 등급 |
| 입구/출구 | 사진분류 전이라 **전부 입구로 가정** |
| 정답 등급 분포 | 상 70 · 중 24 · 하 47 |
| 나누는 법 | 장면 단위 5겹 × 10번 반복 |

## 3. 모델 (EXP-55와 같음 + 1개)

| 비교 묶음 | 모델 | 입력 |
|---|---|---|
| 비교① 사진만 | 규칙1 손 규칙 · 규칙2 경계값 학습 · 규칙3 숫자 하나 직선 · 선형회귀 · LightGBM | 사진 숫자 |
| 비교② 시각·날씨만 | 규칙4 물리 공식 · 규칙5 계절·구름 표 · **LightGBM(사진 안 씀)** | 해 높이 · 구름 · 달 |
| 비교③ 사진이 보태나 | LightGBM+ | 사진 숫자 + 해 높이 · 구름 |

LightGBM(사진 안 씀)은 규칙4·5와 같은 정보를 받는 ML이다. 같은 정보에서 ML과 규칙을 비교하려고 EXP-55 재실행 때 넣었다.

## 4. 결과 (10번 반복 평균, 괄호는 EXP-55 값)

| 비교 묶음 | 모델 | MAE(log) | 순위상관 | 위험도F1 |
|---|---|---|---|---|
| 비교① | 규칙1 | .396 | .29 | .25 (.21) |
| | 규칙2 | .346 | .32 | .29 (.15) |
| | 규칙3 | .343 | .41 | .23 (.18) |
| | 선형회귀 | .232 | .65 | .48 (.36) |
| | LightGBM | .201 | .70 | .56 (.49) |
| 비교② | 규칙4 | .201 | .80 | .52 (.68) |
| | 규칙5 | .102 | .77 | **.79** (.69) |
| | LightGBM (사진 안 씀) | **.062** | **.91** | .78 (.73) |
| 비교③ | LightGBM+ | .079 | .87 | .75 (.75) |

비교 기준선: 전부 "상"으로 찍기 = 위험도F1 약 .25

## 5. 읽는 법

- **비교①** 사진만 쓰면 ML(.56)이 사진 규칙(.23\~.29)보다 확실히 낫다.
- **비교②** 시각·날씨만 쓰면 등급은 ML(.78)과 규칙5(.79)가 비긴다. 밝기 오차는 ML(.062)이 규칙5(.102)보다 낫다.
- **비교③** 사진을 더해도 .78 → .75로 오르지 않는다. 사진이 보태는 몫이 없다.
- 천리안으로 바꿨는데도 사진 안 쓰는 쪽이 강하다. EXP-55의 결과는 "같은 관측소라 유리해서"만으로는 설명되지 않는다.

## 6. 새로 알게 된 것

- 해 높이 하나만으로 정답과 상관 **0.93**.
- LightGBM+의 gain 중요도: 해 높이 82% · 구름 11% · 사진 숫자 합계 7%.
- 예시 사진 2장을 열어 보니 **터널 입구가 안 보였다**. GPS 위치로만 골랐기 때문이다. → 사진이 쓸모없어 보이는 원인일 수 있다.

## 7. 믿기 어려운 점

1. 전부 입구 가정 (출구 사진이 섞이면 등급이 틀림)
2. 터널 입구가 안 보이는 사진이 섞여 있음
3. 141장 · 104장면이라 흔들림이 큼
