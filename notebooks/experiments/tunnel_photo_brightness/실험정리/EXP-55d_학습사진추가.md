# [모델 ③] EXP-55d 학습에 터널 안 보이는 사진 추가

실행 2026-11-05 · 노트북 `07_밝기추정_규칙vsML.ipynb` · 공통 규칙 1판 · 담당 최재혁 (아이디어: 최재혁)
상태: **결과 나옴**

---

## 1. 왜 했나

정답은 사진이 아니라 **위성 일사량**에서 나온다. 그렇다면 터널이 안 보이는 도로 사진도 "그 순간 바깥 밝기" 정답을 가질 수 있다.
학습 사진을 늘리면 ML이 좋아지는지, 규칙은 어떻게 되는지 확인했다.

## 2. 쓴 데이터

| 항목 | 내용 |
|---|---|
| 시험 | **입구·출구 46장으로 고정** (EXP-55c와 같음) |
| 학습 ① | 입구·출구 46장 |
| 학습 ② | ① + 터널 없음 60장 |
| 학습 ③ | ② + 미분류 사진까지, 모두 131장 ('터널 안' 사진은 뺌) |
| 빈칸 처리 | 터널이 안 보이는 사진은 `portal_ratio`(입구 어두움 비)를 빈칸으로 둠 |
| 나누는 법 | 장면 단위 5겹 × 10번. 추가 사진도 **전체 사진의 장면 번호로 먼저 겹을 나눈 뒤 학습 쪽에서만 걸러냄** |

## 3. 장면 섞임 점검

- 추가 사진 중 **13장이 시험 사진과 같은 장면**이었다.
- 장면 번호로 먼저 겹을 나눴기 때문에, 이 13장은 항상 시험 쪽 겹에 들어가고 **학습에는 쓰이지 않았다**.
- 장면 번호가 빠진(−1) 사진은 0장.
- → 누수 없음.

## 5. 읽는 법

- **학습 사진을 늘리면 ML은 좋아지고, 규칙은 그대로이거나 나빠진다.** ML을 쓰는 이유를 보여 주는 결과.
- 터널이 안 보이는 도로 사진도 학습에 쓸 수 있다는 것이 확인됐다.
- 규칙5의 .88은 출구 덕이 아니다. 입구만 봐도 .89\~.90.
- 등급 F1로는 아직 규칙5가 가장 높지만, 학습 ③에서 ML과의 차이는 .03.

## 6. 믿기 어려운 점

- 시험이 46장(입구만은 32장)이라 흔들림이 큼
- 같은 카메라 묶음(Mapillary) 안에서의 비교라 "처음 보는 카메라" 시험이 아님
