## 1. 배경

- 구조를 맞바꿔 본다. 가장 좋은 ML의 구조를 규칙에 넣고, 가장 좋은 규칙의 구조를 ML에 넣는다.

**2단계 로지스틱 방식**
- 1단계: 학습 사진 전부로 "하인가, 위험(중·상)인가"를 로지스틱 회귀로 배움
- 2단계: 학습 사진 중 위험(중·상)인 것만으로 "중인가, 상인가"를 다시 로지스틱 회귀로 배움
- 예측: 1단계에서 하면 하, 아니면 2단계 결과로 중·상
- 공통: 빈칸은 학습 쪽 중앙값으로 채움 → 표준화 → 등급 수 차이를 맞추는 가중(balanced). 규제 세기 C는 {0.01, 0.1, 1, 10} 중 학습 OOF로 고름 → 0.01

**12월을 학습 없이 맞힌 이유**: 모델이 계절이 아니라 해 높이로 판단함 (가중치 1위). 12월 해 높이 19\~27°는 71786의 8\~9월 아침·저녁 사진에도 있는 높이이고 대부분 하. 로지스틱은 직선 관계라 그대로 이어 씀. 부스팅 회귀(나무)는 12월 정확도 .27.

## 4. 구조 맞바꾸기

- **가장 좋은 ML (2단계 로지스틱)의 구조를 규칙에 넣은 결과: .789.**
  - 규칙은 단계마다 숫자 하나와 경계 하나만 쓰고, 경계는 학습 사진에서 고른다.
  - 고른 결과는 두 단계 모두 해 높이였다. 해 높이 35.5° 이하면 하, 51.3°를 넘으면 상, 그 사이는 중이다.
  - 깊이 2 나무로 만든 3분류 규칙도 똑같은 규칙이 됐다.
  - 이 규칙이 새 "최고 규칙"이다. ML과의 차이는 +.036으로 **비슷**하다.
- **이전 최고 규칙 (물리 공식, 회귀→등급)의 구조를 ML에 넣은 결과.**
  - 부스팅 회귀(현 주 모델) .526, 물리 공식 + 사진 보정 .618이다.
  - 둘 다 2단계 구조보다 크게 낮다.
- **최고 ML과 최고 규칙의 구조 차이.**
  - 규칙: 해 높이 하나에 경계 2개뿐이다.
  - ML: 같은 2단계에 12개 숫자를 가중합한다.
  - 1단계 가중치: 해 높이 1.51, 구름 −0.48, 파란 하늘 0.33, 나머지는 0.15 이하다.
  - 2단계 가중치: 해 높이 1.67, 구름 −0.64, 파란 하늘 0.43, 도로 밝기 0.25.
  - 점수 차이는 +.036이고, 95% 범위가 0을 포함한다.

## 5. 원인 분석

- **점수를 올린 것은 하이퍼파라미터가 아니라 구조였다.**
  - 같은 부스팅 회귀를 F1 기준으로 다시 튜닝하면 .526에서 .490으로 오히려 떨어졌다.
  - 회귀로 밝기를 먼저 맞히고 등급으로 바꾸는 방식에서는, 작은 밝기 오차가 등급을 뒤집는다.
  - 입구 등급은 밝기에 대해 계단 모양이라 더 그렇다. 조광 4단계 때문에 L20이 700\~1,000이면 중, 1,000\~1,400이면 다시 하가 된다.
  - 등급을 바로 맞히면 이 문제를 피한다.
- **"달" 숫자를 넣으면 무너진다 (.329).** 학습은 8\~9월뿐이고 시험은 12월과 5월이 대부분이라, 달 값이 엉뚱하게 쓰인다. 달은 빼야 한다.
- **사진만으로도 2단계에서는 .713이 나온다.** 회귀(사진만)는 .196이었다. 사진에도 신호는 있다는 뜻이다.

## 6. 약점 (비판)

1. **높은 점수의 대부분은 해 높이 하나로 설명된다.**
   - 해 높이만 쓴 규칙이 .789다. ML은 이를 넘지 못한다(비슷).
   - 정답 자체가 위성 일사량에서 나오고, 일사량은 대부분 해 높이와 구름으로 정해지기 때문이다.
   - "ML이 사진에서 더 배운다"는 주장은 아직 약하다. 사진의 몫은 해높이+구름 대비 +.105가 유의하고, 해 높이만 대비로는 유의하지 않다.
2. **시험이 계절로 갈린다.**
   - 입구 66장 중 12월이 22장(대부분 하), 5월이 28장(대부분 상)이다.
   - 그래서 F1 .8은 "겨울/늦봄 구분"을 잘한 결과일 가능성이 크다.
   - 중 등급은 9장뿐이고, 중 재현율은 .44\~.56으로 약하다.
   - **확인 결과**: 12월 22장은 정답이 전부 하이고, 5월 28장은 전부 상이다.
   - 2단계 ML은 이 두 묶음을 100% 맞혔다. 나머지 16장(중 9, 하 6, 상 1)의 정확도는 .62에 그쳤다.
   - 같은 16장에서 2단계 해 높이 규칙은 .62, 현 주 모델(부스팅 회귀)은 .69다.
   - 즉 **어려운 장면에서는 2단계가 더 낫지 않다.** 점수가 오른 것은 쉬운 계절 묶음(특히 12월 하)을 바로잡은 덕이다. 현 주 모델은 12월을 .27밖에 못 맞혔다.
3. **후보 18개를 같은 시험에서 채점했다.** 시험 점수 1등을 고르면 운이 섞인다. 주 모델은 학습 OOF F1 1등으로 고르는 게 맞다. 이번에도 1등은 같은 모델(.691)이었다.
4. **시험 구름 칸의 1/3이 비어 있다** (입구 22장). 그래서 해높이+구름 모델이 해 높이만 모델보다 낮게 나왔을 수 있다.
5. **09 블랙박스로 새 모델을 아직 검증하지 않았다.** 09는 구름 칸도 아직 비어 있다.

## 8. 추가 (11/6 04:12 형 결정): 추정 바깥 밝기를 2단계의 변수로 → **최종 주 모델**

**왜**: 형 지적. 2단계 로지스틱만으로는 "사진 → 바깥 밝기" 고리가 빠지고, 동공 모델에 넘길 밝기가 없음.

**데이터·방법 (②a, 위와 같음)**
| 항목 | 내용 |
|---|---|
| 학습 | 71786 3,624장 (8\~9월) |
| 시험 | Mapillary 입구 66장 (51장면), 참고 93장 |
| ① 밝기 추정 | 직선 회귀(Ridge α=10), 입력 = 사진 숫자 10개 + 해 높이 + 구름, 정답 = log10(L20) |
| 새는 길 막기 | 학습 사진의 추정 밝기는 학습 안 5겹 OOF 값만 씀 (자기 정답 본 모델의 밝기를 받으면 너무 잘 맞는 것처럼 보임). 정답 밝기는 넣지 않음 |
| ② 등급 | 2단계 로지스틱, 입력 = 위 12개 + 추정 밝기 (13개). C는 학습 OOF F1로 고름 → 0.01 (OOF .696) |
| 후보 비교 | 밝기 추정 모델 3종(직선 해높이+구름 · 직선 사진+ · 부스팅 07) × 2단계 입력 3종 = 9개를 같은 시험으로 봄 |
