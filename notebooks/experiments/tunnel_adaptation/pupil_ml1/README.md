# ML-1: 빛 이력에 따른 동공 지름 추정

SpectroSense 실제 동공 지름(mm)을 정답으로 규칙·선형회귀·LightGBM을 비교한 모델③ 보조 실험이다. 현재 서비스의 순응 점수나 사고 모델을 교체하지 않는다.

## 결과 — 2026-11-05

기본 표본 12,203행·83명의 참가자 단위 5겹×10회 MAE(mm): 규칙 **0.766**, 현재 조도·나이 ML **0.780**, 이력 ML **0.610**. 현재값 ML의 우위는 확인하지 못했다.

완전한 직전 1분 이력이 있는 동일 10,526행·83명에서 정보량을 맞춰 비교했다.

| 입력/모델 | MAE(mm) |
|---|---:|
| 현재값 규칙 | 0.722 |
| 직전 1분 기하평균 규칙 | 0.639 |
| 직전 1분 산술평균 규칙 | 0.669 |
| 현재값 ML | 0.717 |
| 현재값+10초 전 ML | 0.680 |
| 현재값+직전 1분 ML | 0.583 |
| 전체 이력 ML | 0.562 |

전체 이력 ML−기하평균 규칙 MAE 차이는 **−0.077mm**(참가자 재표집 95% 구간 −0.123\~−0.026mm)다. 오차는 감소했지만 사전 기준 0.1mm 개선에는 미달했다. 직전 조도 대비 **3배 초과 변화 1,159행**에서는 차이 **−0.116mm**(−0.165\~−0.067mm), 순위상관 증가로 세 기준을 충족했다. 급변을 제외한 9,367행은 −0.072mm로 기준 미달이다.

## 방법과 해석

- 기본 학습은 동공/조도 결측 제외, confidence≥0.8, Field/Lab만 사용한다. Field는 실내·실외 일상 조건이다. Dark는 별도 기술통계다.
- 이력은 현재 관측을 제외한 과거 조도이며 동공 정답은 입력하지 않는다. 추가 대조는 과거 6개 관측이 실제 60초를 구성하는 행으로 맞춘다.
- 규칙 시야 면적은 학습 폴드에서 314·1,000·3,000deg² 중 선택한다. 같은 참가자는 학습/시험에 함께 들어가지 않는다.
- 우위 기준은 MAE≥0.1mm 감소·참가자 군집 구간 상한<0·순위상관 증가다. 0.1mm는 임상 기준이 아니다. MAE는 측정 행 가중이다.
- 기본 판정/부분집단은 반복0 OOF, 추가 판정은 10회 고정 OOF의 평균 절대오차다. 재표집 구간은 고정 예측에 조건을 둔 것으로 전체 재학습 불확실성이 아니다.
- 현재값 ML에는 현재 조도 단조 감소 제약이 있고 이력 ML은 제약이 없다. 따라서 이력 제거 비교에는 제약 설정 차이도 포함되며, 특성만 바꾼 순수한 제거 실험으로 해석하지 않는다.
- 단순 평균을 넣은 두 이력 규칙과의 비교이며 가능한 모든 동적 생리 규칙과 비교한 것은 아니다. 급변 부분집합은 별도 터널 검증을 대체하지 않는다.
- Dark 첫 유효 관측 기준 35초와 첫 Dark 기록 기준 50초는 서로 다른 기술통계다. 최대 지름 90%의 첫 관측을 암순응 완료시간으로 해석하지 않는다.
- 동공 지름 추정은 순응 완료시간·시야 저하·사고확률 예측이 아니다. lux/π·휘도×π는 균일 시야 가정이며 사진 밝기를 바로 조도로 취급하지 않는다.
- 동공표/로컬 모델 저장 대상은 현재값 후보다. 가장 좋은 이력 모델의 배포 파일이 아니다. 입구 밖→안/출구 안→밖 방향과 반올림 전 비율을 별도 점검한다. 휘도비 경계 10·15와 내부 휘도는 검증된 사고 기준이 아니다.

## 실험 파일

- `pupil_ml1.ipynb`: 기본 비교, 저조도 제외 민감도, 이력 규칙 대조·이력 제거·급변 분석, 시점/방향 점검. 집계 표와 그림을 실행 출력으로 보존했다.
- `results.json`: 원본 데이터나 개인별 예측을 포함하지 않는 집계 결과. 노트북의 마지막 셀이 로컬 출력에 같은 구조를 생성한다.
- `requirements.txt`: 기준 분석·노트북 실행 환경 버전(Python 3.13).

입력은 `data/spectrosense/merged_data_incl.csv`, 생성물은 `data/pupil_ml1_results/`가 기본이다. 필요하면 `PUPIL_DATA_PATH`·`PUPIL_OUTPUT_DIR`로 바꾼다. 원본 CSV·개인별 관측/분할/OOF·모델 파일은 저장소에 포함하지 않는다. 별도의 팀원용 문서와 공유 ZIP도 포함하지 않는다.

출처: Lazar 등, *Regulation of pupil size in natural vision across the human lifespan*, [SpectroSense 가공자료](https://doi.org/10.6084/m9.figshare.24230848.v3), CC BY 4.0. 입력 SHA-256은 `results.json`에 기록한다. 규칙 공식은 기존 실험의 Watson–Yellott(2012) 구현을 유지했다.
