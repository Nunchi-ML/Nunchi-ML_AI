# 모델 ③ 터널 진입 · 진출 순응 부담 (v2, 2026-11-02)

터널에 들어갈 때(밝음 → 어둠)와 나올 때(어둠 → 밝음) 눈이 적응하는 부담 **A**가 고속도로 사고를 몇 배 늘리는지 본다.

## 노트북

| 노트북 | 하는 일 |
|---|---|
| `01_load_data` | 사고 · 터널 원본 불러오기 |

## 실행 순서

`01` → `05` → `07` 순서로 실행한다.

- `rules/방향규칙표.csv` 를 `data/2_중간/` 에 복사 후 03 실행
- `.env` 에 `DATA_GO_KR_KEY=인증키` 를 넣는다 (공유 금지). 원본 · 결과 데이터는 저장소에 올리지 않는다

## 천리안 위성 일사량 민감도 (2026-11-04)

> ⚠️ 순응 점수 A 계산은 초안 · 업데이트 중 (담당자 검토 전)

- 왜: ASOS 일사 관측소가 사고 자리에서 멀어(중앙값 16.8 km) 측정 오차 때문에 결과가 흐린지 확인
- 방법: 순응 구간 낮 사고 묶음 자리마다 천리안2A AI 일사량(기상청 API허브)을 사고 앞뒤 1시간만 요청 (한 번에 24개 한도, 시각 UTC, 단위 MJ/m² 1시간 합) — `04b_천리안_일사량.ipynb`
- ASOS와 비교: 상관 0.896 (887일), 중앙값 비 1.0, 0.5 MJ 넘게 차이 나는 날 12%

| 일사량 | 진입 A 0.1당 사고 위험 | 95% 범위 |
|---|---|---|
| ASOS (재실행, 진입 낮 136묶음) | 1.22배 | - |
| 천리안 위성 | 1.16배 | 0.87 ~ 1.53 |

- 진출은 어느 쪽으로도 신호 없음
- 해석: 범위가 1을 포함 → 경향 수준이고 효과 크기가 작음. 범위가 넓은 이유는 측정이 아니라 사고 수(진입 낮 136건)
- 결정(담당자 확인 전): 주 분석은 ASOS 유지, 천리안은 민감도 분석
