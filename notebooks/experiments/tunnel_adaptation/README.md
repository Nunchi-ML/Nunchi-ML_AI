# 모델 ③ 터널 진입 · 진출 순응 부담 — 데이터 파이프라인 (2026-11-02)

터널에 들어갈 때(밝음 → 어둠)와 나올 때(어둠 → 밝음) 눈이 적응하는 부담 **A**가 고속도로 사고를 몇 배 늘리는지 보기 위한 데이터 준비 단계다. 결과는 대구 출퇴근 경로(신천대로 · 경부고속도로 · 달구벌대로) 지점 · 시각별 사고확률로 이어진다.

> ⚠️ **순응 점수 A 계산 과정은 아직 업데이트 중이다.** 담당자(최재혁) 검토 전 초안이라 상수 · 식 · 구간 범위가 바뀔 수 있다.

## A 점수 계산 (초안 · 검토 중)

> 아래 계산식과 상수(발광효율 126, 반사율 0.15, 터널 휘도 280 · 45)는 아직 검토하지 않은 초안이다. 값과 식이 바뀔 수 있다.

| 단계 | 식 | 예) 맑은 한낮 일사 3.0 |
|---|---|---|
| 햇빛 세기 | 일사량 × 277.8 | 833 W/m² |
| 바깥 조도 | × 126 lm/W | 105,008 lx |
| 바깥 휘도 L20 | 0.15 × 조도 ÷ π | 5,014 cd/m² |
| 터널 안 휘도 | 입구 280 × 조광 단계 / 출구 45 (국토부 조명 지침 6장) | 280 / 45 |
| 점수 | log10(휘도비) ÷ 2, 0~1 | A_진입 0.63 · A_진출 1.00 |

- A_진입은 입구 150 m 앞 ~ 입구 안 100 m, A_진출은 출구 60 m 앞 ~ 출구 뒤 150 m에서만 켜고 나머지는 0
- 해 방향(역광)은 모델 ② · 눈부심 쪽 몫이라 A에 넣지 않는다

## 검증 방법

- **같은 자리 비교 (case-crossover)**: 사고 1건마다 같은 자리 · 같은 달 · 같은 요일 · 같은 시각의 다른 주 3~4개를 평소(0)로 둔다. 장소 차이가 지워져 A · 날씨처럼 시간에 따라 바뀌는 것의 효과만 남는다
- 분석은 조건부 로지스틱 회귀, 결과는 "A가 0.1 오르면 사고 오즈 몇 배"로 읽는다
- 민감도: 입구 휘도 140 · 420, 출구 30.7, 조광 없음, 점수 ÷ 3

## 한계 — 다음에 할 일

1. 원본 파일(OSM zip · ASOS 관측소 목록 · 교통량 VDS) 받아서 03~06 실행
2. 터널별 실제 조명 값이 없어 모두 지침대로 켰다고 가정한다
3. 일반도로(신천대로)는 분 단위 개별 사고 공개 데이터가 없어 고속도로로 학습한 배수를 적용한다
4. 교통량을 붙여 그날 교통량 차이를 보정한다

## 다시 돌리기

```bash
pip install -r requirements.txt
python -m src.tunnel.adaptation 3.0 1.0 0.3      # A 점수 예시
```

노트북은 `01` → `06` 순서로 실행한다. 노트북 폴더 아래 `data/1_원본`(받은 그대로) · `data/2_중간` · `data/3_결과`를 만들고, `.env`에 `DATA_GO_KR_KEY=인증키`를 넣는다 (공유 금지).
