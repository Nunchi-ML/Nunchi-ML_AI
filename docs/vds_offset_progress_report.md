# SunSight Model 1 — VDS 교통 노출량 보정 실험 및 검증 기술 보고서

## 1. 개요 및 실험 목적
기존 Model 1은 고속도로 1km 구간당 '정면 역광 사고 건수($Y_i$)'를 예측하는 모델로 개발되었다. 그러나 사고 건수 중심 평가는 통행량이 집중되는 주요 간선도로(예: 경부선)의 자연스러운 사고 빈도와 도로 환경 고유의 위험도를 분리하지 못하는 한계가 있다.

이에 따라 한국도로공사 VDS 3개년(2023~2025) 실측 월간 교통량 데이터를 전수 집계하여 구간별 일평균 교통량(AADT)을 산출하고, 차량 주행거리(VKT) 기반 교통 노출량($E_i$)을 Poisson Offset($\log(E_i)$)으로 반영하는 사고 발생률 모델링의 타당성을 검증하였다.

$$\log(\lambda_i) = \log(E_i) + \beta_0 + \sum_{k} \beta_k X_{ik}$$

---

## 2. VDS 실측 데이터 정제 및 이정표 원점 매핑 분석

### 2.1 3개년 VDS 전수 집계
- **원천 데이터**: `VDS 소통/unzipped/` 내 50개 월별 CSV 파일 중 2023년 1월 ~ 2025년 12월 (총 34개 월간 전수 파일)
- **산출 아티팩트**: `data/expressway/vds_aadt_2023_2025.csv`
- **집계 결과**: 전국 고속도로 총 **8,624개 VDS 지점**, 평균 관측 월수 31.7개월, AADT 중앙값 **12,519 대/일**.

### 2.2 복합 노선명 정규화 및 원점 보정
단순 문자열 매칭의 한계를 극복하기 위해 도로공사 중심선 이정좌표와 대조하여 이정표 원점 체계를 정규화함:
- `통영대전선/중부선`: 0~214km(통영대전선 0351 본선 이정), 215~364km(중부선 0352 대전기점 이정 변환 $\text{seg\_km} - 215.0$)
- `논산천안선/호남선`: 호남선 본선(0251) 체계 연계
- `서산영덕선`: 청주상주, 상주영덕, 당진대전 구간별 노선 코드 분기 매핑
- **매핑 검증**: 단순 매칭 시 2,469개(42.7%)에서 원점 보정 후 **3,304개(57.1%)**로 실측 표본을 확장 확보함.

## 3. 동일 표본(Identical Cohort) 비교 실험 및 한계 규명

### 3.1 실험 설계 및 결측 표본 처리
- **표본 정제**: 3,304개 매핑 구간 중 VDS AADT가 0인 181개 구간을 검토한 결과, 실제 통행량이 없는 구간이 아니라 **검지기 고장 또는 통신 누락에 따른 데이터 결측**으로 확인됨. 해당 구간을 임의의 하한값(예: 1,000)으로 대체하는 방식은 사고율 왜곡을 유발하므로 정제 대상에서 제외함.
- **동일 검증 표본**: 결측이 배제된 **3,113개 유효 구간 (정면 사고 53건)**에서 기존 모델과 Offset 모델을 동일한 61개 노선 단위 5-Fold GroupKFold로 재학습 및 교차검증함.

### 3.2 실험 결과 및 구현상 한계 발견
| 평가 지표 | 기존 Model 1 (건수 기준) | Offset Model (사고율 기준) | 비고 |
| :--- | :---: | :---: | :--- |
| **Poisson Deviance (건수 scale)** | **0.1276** | 1.9695 | Offset 구현 시 과대 예측 문제 확인 |
| **사고 건수 포착률 (Top 10%)** | **24.5%** | 3.7% | 건수 포착 목적 지표 |
| **고위험 순위 교체율 (vs Base)** | 기준 (0.0%) | **87.5% 전면 재편** | 상위 위험 구간 구성의 급격한 변동 |
| **실측 사고율($y_i/E_i$) Top 10% 일치율**| **19.0%** | **5.5%** | 무작위 기대치(10%) 미달 |

### 3.3 핵심 발견 및 실패 원인 분석
1. **LightGBM init_score의 Offset 활용 한계**:
   - 트리 기반 모델에서 거대한 스케일의 $\log(E_i) \approx 18$을 초기 점수로 주입할 경우, 얕은 트리 구조와 정규화 제약 하에서 잔차를 충분히 깎아내리지 못해 예측값 $\hat{\lambda}$가 수백 건 수준으로 과대 예측되는 현상이 발생함.
2. **저노출 구간에서의 사고율 추정 불안정성**:
   - 예측 사고율 $\hat{r}_i = \hat{\lambda}_i / E_i$로 위험 순위를 산출한 결과, 분모($E_i$)가 상대적으로 작은 저교통량 구간에서 사고율이 과도하게 증폭되어 상위 10% 순위에 노이즈 형태로 집중되는 현상이 관찰됨.
   - 그 결과, 실측 사고율 상위 구간 포착 능력이 5.5%로 떨어져 현 구현을 정책적 위험 구간 탐지 모델로 활용하기에는 한계가 있음을 확인함.

## 4. 최종 결론 및 향후 기술적 방향

1. **정식 서비스 모델 확정**:
   - 기존 **Model 1 (LightGBM 단일 모델, Poisson Deviance 0.1276~0.1299, 사고 건수 포착률 24.5%)을 정식 서비스 모델로 유지**함. 실시간 내비게이션 운전자 경고 목적에서는 절대 사고 발생 빈도 기준의 지표가 더 안전하고 직관적인 기준을 제공함.
2. **Offset 모델의 연구적 가치와 교훈**:
   - VDS 3개년 전수 집계 및 이정표 원점 정규화 파이프라인(3,113개 실측 표본)을 확보함.
   - 단순 나눗셈 기반의 노출량 보정이 저노출 구간에서 유발하는 추정 불안정성을 실증적으로 규명함.
3. **향후 고도화 과제 (Empirical Bayes Smoothing)**:
   - 극단적 저노출 구간의 사고율 추정치를 전체 평균 및 유사 노선 방향으로 안정화하는 **경험적 베이즈(Empirical Bayes) 평활화** 및 계층적 Poisson 모델을 도입하여, 사고율 기반 위험 구간 탐지 성능을 개선할 계획임.
