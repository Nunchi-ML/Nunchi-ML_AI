# 시뮬레이터 요청서 v3 — 모델③

Nov 7, 2026 · @최재혁

## 1. 보여줄 것

1인칭 운전 화면에서 차가 신천대로 지하차도에 다가갈 때, 모델 ③이 "지금 이 입구가 위험하다"고 알려 주는 장면입니다. 알림이 뜨고, 입구에 들어가는 순간 운전석 시야가 어두워졌다가 3초에 걸쳐 다시 보이게 됩니다. 얼마나 어둡게 시작하는지는 모델 ③의 등급(하 · 중 · 상)이 정합니다.

## 2. 장면 순서 (1인칭 운전석 시점)

1. **입구 155m 전 (155m 값은 표시 안하게)**: 앞 유리 위쪽에 알림이 뜨고 경고음이 울림. 예: "모델 ③ · 전방 지하차도 입구 순응 위험 상". 색은 하 초록/ · 중 노랑 /· 상 빨강
2. **입구 통과 순간**: 운전석에서 보이는 화면 전체가 한꺼번에 어두워짐. 어둡기는 아래 표
3. **들어간 뒤 3초**: 화면 가운데 3 · 2 · 1. 처음에는 빨리, 나중에는 천천히 밝아짐
4. **0초**: 최소 시야 확보. 화면이 평소 밝기로 돌아옴

| 등급 | 들어간 순간 화면 어둡기 | 1초 뒤 | 2초 뒤 | 3초 뒤 |
| --- | --- | --- | --- | --- |
| 상 | 85% (거의 깜깜) | 38% | 9% | 0% |
| 중 | 60% | 27% | 7% | 0% |
| 하 | 30% (살짝) | 13% | 3% | 0% |

- 어둡기 = 화면 위에 덮는 검은 막의 진하기. 0.5초 간격 값은 API가 줍니다.
- 차 속도가 바뀌어도 3초는 그대로 둡니다.
- 같은 지하차도를 두 번 달려 주세요. 맑은 날 한낮(상)과 흐린 날(하). 햇빛에 따라 알림과 어둡기가 달라지는 것이 보이면 됩니다.

## 3. 화면 요소와 API 칸

| 번호 | 화면 요소 | API 칸 |
| --- | --- | --- |
| 1 | 알림 색 · 등급 | `grade` (하 · 중 · 상) |
| 2 | 알림이 뜨는 거리 | `warn_distance_m` (155) |
| 3 | 화면 어둡기와 3초 회복 | `screen_effect` (시작 어둡기, 0.5초 간격 곡선, 카운트다운 3 · 2 · 1) |

## 4. 지켜 주세요

- 화면 문구에 "여기서 사고가 난다", "사고 확률 몇 %"는 넣지 마세요. "순응 위험 하 · 중 · 상"만 씁니다.
- 지하차도 출구에는 모델 ③ 알림을 띄우지 마세요.

## 5. API 사용법

코드는 `sunsight_api` 폴더에 있습니다(README 포함). 서버를 켜고 `http://localhost:8000/docs`를 열면 입력 칸이 있는 시험 화면이 나옵니다.

```
pip install -r requirements.txt
python train_model.py --train ../sunsight_video/data/aihub_71786/학습표_71786.csv
uvicorn api:app --host 0.0.0.0 --port 8000
```

| 주소 | 용도 | 입력 |
| --- | --- | --- |
| `POST /predict/photo` | 사진으로 바로 판정 | `image`, `captured_at`(한국 시각), `lat`, `lon`, `cloud`(0\~10, 모르면 비움) |
| `POST /predict/features` | 사진 숫자를 미리 계산해 둔 장면 여러 개 | JSON 배열 (`id`, `features`, `sun_alt` 또는 시각 · 위치, `cloud`) |
| `GET /health` | 서버 확인 | 없음 |

시뮬레이터 장면이 그린 화면이라면, 장면마다 공개 사진(Mapillary) 한 장을 미리 넣어 결과를 받아 두고 재생하면 됩니다.
